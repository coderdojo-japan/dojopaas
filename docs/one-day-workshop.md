# 1日ワークショップ用のサーバー

ふだんの Dojo 用サーバーは 1コア 1GB です。これは Web サイトの公開や小さなアプリには十分ですが、
**1日だけのワークショップ**で、参加者がいっせいに同じサーバーを使う場合には足りないことがあります。

そういう日のために、**開催日を書くと、ふだんの 8 倍のサーバーが作られる**ようになっています。
申請の流れは、ふだんのサーバーとまったく同じです。

<br>

## スペック

| | ふだんのサーバー | ワークショップ用 |
|---|---|---|
| CPU | 1コア | **8コア** |
| メモリ | 1GB | **8GB** |
| ディスク | 20GB | 20GB |
| OS・リージョン・開放ポート | 変わりません | 変わりません |

<br>

## 申請のしかた

[servers.csv](https://github.com/coderdojo-japan/dojopaas/blob/main/servers.csv) に行を足す
プルリクエストを送ります。ふだんと違うのは、次の **2 つの書き方だけ**です。

```csv
name,branch,description,pubkey
coderdojo-naha-workshop,workshop-20261115,1日ワークショップ用のサーバーです。,ssh-rsa AAAA...
```

### 1. `branch` に開催日を書く

ふだんは道場名を書く欄ですが、ワークショップ用は**ここに開催日**を書きます。
`workshop-YYYYMMDD` の形です。上の例は 2026年11月15日の開催です。

**この形のときだけスペックが上がります。** `workshop` だけや `workshop-2026-11-15` のような
書き方だと、ふだんと同じ 1コア 1GB で作られてしまうので、テストが失敗し、
bot が直し方をコメントします。

### 2. `name` を `-workshop` で終わらせる

`coderdojo-<道場名>-workshop` のように書きます。ふだんのサーバーと並んだときに、
どちらがワークショップ用か見分けられるようにするためです。名前は他と重複しないようにしてください。

<br>

## プルリクエストを送ると、その場で返事が来ます

マージを待たずに、**bot が PR にコメントします**。読み取れた内容がそのまま出るので、
書き方が合っているかを送った直後に確認できます。

```
### ワークショップ用サーバーとして受け付けました

| サーバー名 | 開催日 | スペック |
|---|---|---|
| `coderdojo-naha-workshop` | 2026-11-15 | 8コア / 8GB（ふだんの8倍） |
```

書き方が合っていないときは、どこをどう直せばよいかがコメントに出ます。
直して push すると、コメントも書き換わります。

<br>

## 作成と削除

- **作成**: PR がマージされると作られます（ふだんの流れと同じです）。
  IP アドレスは[サーバーの一覧表](https://github.com/coderdojo-japan/dojopaas/blob/gh-pages/instances.csv)に載ります
- **削除**: 開催が終わったら、[servers.csv](https://github.com/coderdojo-japan/dojopaas/blob/main/servers.csv)
  からその行を削除する PR を送ってください（→ [README「サーバーが不要になったとき」](../README.md#3-サーバーが不要になったとき)）

サーバーの台数には限りがあり、みなさんで共同利用しています。
申請は**開催日の前日まで**、削除は**開催が終わったら翌日を目安に**していただけると、
他の Dojo も使いやすくなります（枠に余裕があるときは、この限りではありません）。

申請にはマージする人の対応が必要で、IP アドレスが一覧表に載るまでにも時間がかかります
（→ [README「SSHの接続方法」](../README.md#2-sshの接続方法)）。
当日になってからでも枠があれば作れますが、前日までにお送りいただけると確実です。

<br>

## よくある質問

### Q. ふだん使っているサーバーを、その日だけ速くできますか?

できません。ワークショップ用は**別の 1 台**として作ります。
ふだんのサーバーはそのまま残るので、当日までの準備と当日の運用を分けられます。

### Q. 8 倍で足りない場合は?

[Issue](https://github.com/coderdojo-japan/dojopaas/issues) でご相談ください。
どのくらいの規模で、何をされるのかを書いていただけると検討しやすいです。
